# howyoushouldliveyourlife.com

Fourteen rules for living at the scale humans are built for. Part of Demismatch.
Plain static files: `index.html`, `look.css`, `style.css`, `fonts/`.
`look.css` is the one look for every Demismatch site (colours, typefaces, text sizes, the top bar, the Cor banner, the foot). It is a copy. Change the master, never this copy.
Serve the repo root as it is (GitHub Pages, branch main). The domain is set in `CNAME`.
The master copy and its notes live in the private repo MaartenRischen/demismatch-workspace, folder `howyoushouldliveyourlife/`.
